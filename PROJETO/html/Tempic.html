O problema que o TEMPIC resolve

⚠️

Problema

Em muitos laboratórios e pequenas indústrias, o monitoramento de temperatura ainda é feito de forma manual ou com equipamentos caros, dificultando a detecção de variações críticas.

📉

Consequência

Falhas na detecção precoce podem levar a perda de materiais, resultados de experimentos comprometidos e até riscos à segurança.

💡

Necessidade

Uma solução acessível, de código aberto e fácil de replicar, que permita monitoramento contínuo e alertas em tempo real.

O TEMPIC atua como um sistema de aquisição de dados térmicos, processando as informações localmente e exibindo em um painel simples, permitindo ações corretivas rápidas.

Como o TEMPIC funciona?

01

Coleta

Sensor LM35 conectado ao microcontrolador Arduino captura a temperatura do ambiente a cada segundo.

02

Processamento

O Arduino converte o sinal analógico em valor digital, aplica um filtro simples e armazena em buffer.

03

Transmissão

Os dados são enviados via comunicação serial (USB) para o computador, onde o dashboard os interpreta.

04

Monitoramento

O dashboard exibe gráficos, indicadores e alertas visuais sempre que a temperatura ultrapassa limites configurados.

05

Análise

O usuário pode exportar os dados para planilhas e analisar tendências ao longo do tempo.

Funcionalidades

🌡️

Leitura contínua

Coleta automática de temperatura a cada segundo com precisão de ±0,5°C.

📈

Dashboard ao vivo

Painel visual com medidor, gráfico de tendência e último valor registrado.

🔔

Alertas configuráveis

Defina limites mínimo e máximo para receber notificações visuais no dashboard.

💾

Exportação de dados

Salve o histórico em formato CSV para análise em ferramentas externas.
